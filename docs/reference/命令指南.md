# Skill Seekers 命令指南

本指南面向日常使用和 fork 开发者，按“从输入到输出”的流程组织所有 CLI 命令。

## 0. Fork 开发者优先安装方式

在 fork 中开发时，优先使用本地编译覆盖安装：

```bash
python3 -m pip install --user --no-build-isolation --force-reinstall --no-deps .
```

说明：
- 该命令会让 `skill-seekers` 使用你当前本地源码，而不是旧的 PyPI 安装包。
- 每次改完代码后都建议重新执行一次。

## 2. 采集类命令（输入源）

### 2.1 通用入口（推荐）

`create` 自动识别来源类型（URL / GitHub / 本地目录 / PDF / 配置文件）：

```bash
skill-seekers create https://docs.react.dev/
skill-seekers create facebook/react
skill-seekers create ./my-project
skill-seekers create manual.pdf
```

常用参数：
- `-p, --preset quick|standard|comprehensive`
- `--enhance-level 0|1|2|3`
- `-o, --output DIR`
- `--enhance-workflow ...`

### 2.2 文档站点

```bash
skill-seekers scrape --config configs/react.json
```

### 2.3 GitHub 仓库

```bash
skill-seekers github --repo owner/repo --name myskill
```

### 2.4 PDF

```bash
skill-seekers pdf --pdf ./doc.pdf --name mypdfskill
```

### 2.5 Word（.docx）

```bash
skill-seekers word --docx ./manual.docx --name mywordskill
```

### 2.6 视频（YouTube / 本地）

```bash
skill-seekers video --url https://www.youtube.com/watch?v=...
skill-seekers video --setup
```

### 2.7 多源合并（docs + github + pdf + local）

```bash
skill-seekers unified --config unified.json
```

常用参数：
- `--merge-mode rule-based|claude-enhanced`
- `--fresh`
- `--dry-run`
- `--enhance-workflow ...`
- `--keep-inter`（保留每个 lecture 的中间目录）

## 4. 打包、上传、安装类命令

### 4.1 打包（平台导出）

```bash
skill-seekers package output/react --target claude
skill-seekers package output/react --target gemini
skill-seekers package output/react --target openai
skill-seekers package output/react --target langchain
```

重点：
- `--target` 在 `package` 阶段使用，不在 `create` 阶段使用。

### 4.2 上传

```bash
skill-seekers upload output/react-claude.zip
```

### 4.3 安装到 Agent

```bash
skill-seekers install-agent output/react --agent claude
skill-seekers install-agent output/react --agent all
```

### 4.4 一体化安装流程

```bash
skill-seekers install --help
```

## 8. 常见误区

- 误区：`skill-seekers create ... --target claude`
  - 正确：`create` 生成内容，`package --target claude` 导出平台包。

- 误区：对纯 PDF 目录用 `create ./dir` 期望 lecture 索引
  - 正确：用 `unified --config ...`，在 `sources` 中显式声明每个 `type: "pdf"`。

- 误区：fork 改完代码直接运行，结果还是旧行为
  - 正确：先执行本地覆盖安装命令，再运行 CLI。
